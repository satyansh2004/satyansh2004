## 04 / WHAT I’M LEARNING THE HARD WAY

> **Abstractions are useful. Understanding what is underneath them is better.**

```text
Application
    │
    ▼
Libraries / APIs
    │
    ▼
Operating System
    │
    ├── processes
    ├── virtual memory
    ├── system calls
    └── scheduling
    │
    ▼
Architecture
    │
    ├── ISA
    ├── registers
    ├── caches
    └── interrupts
    │
    ▼
Firmware / Bare Metal
    │
    ├── peripherals
    ├── timers
    ├── DMA
    └── memory mapped I/O
    │
    ▼
Silicon
```
